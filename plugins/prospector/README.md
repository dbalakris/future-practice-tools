# prospector

Placeholder. Version 0.0.1 exists to test that this marketplace installs. The tool itself, with its setup, collect, contact and sweep skills, ships as 1.0.0.

What it will do: take your ideal-customer triggers (the events that make a company a live prospect), search the sources you name, exclude your existing clients, and write results to the surface you choose. Your configuration and client list stay in your own project; this plugin never holds them.
